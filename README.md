The funniest sign for the door of a haunted server room (100 characters): the ghost in rack 3 has root access, and the last sysadmin who walked in without knocking got rm -rf'd. A tiny program (`main.ts`) writes the line into `/output/entry.txt` for make.fun's "Funniest Sign on a Haunted Server Room Door" bounty.

## Run it

```sh
node main.ts
```
